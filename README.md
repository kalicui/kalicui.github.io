# openXD 迅达项目主页

这是 openXD 迅达的静态项目主页，用于介绍并链接到现有网站和工具。页面使用原生 HTML 与 CSS，不需要安装依赖或运行构建流程。

## 页面内容

- 首页介绍与项目导航
- QSL 电子卡和通联日志
- 太原新希望双语学校网站
- 迅达购物页面演示
- 联系邮箱：<javasq56x@gmail.com>

## 本地预览

直接在浏览器打开 `index.html` 即可预览。也可以使用任意静态文件服务器从项目根目录启动。

## 目录结构

```text
.
├── index.html          # 主页结构与内容
├── css/index.css       # 主页样式
├── qsl/                # QSL 卡与通联日志
├── New_Dream_School/   # 学校网站
└── ShopOnine/          # 购物页面演示
```
